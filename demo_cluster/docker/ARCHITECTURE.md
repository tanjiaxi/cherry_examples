## 网络通信流程

```
客户端
  │
  │ WebSocket/TCP
  │ (Port 3011)
  ▼
┌─────────────┐
│ Gate 节点   │
└──────┬──────┘
       │
       │ RPC 调用
       │ (NATS)
       ▼
┌─────────────┐
│ Game 节点   │
└──────┬──────┘
       │
       ├─ 查询服务发现 (ETCD)
       │
       ├─ 发送消息 (NATS)
       │
       └─ 查询数据库 (PostgreSQL)
```

## 服务依赖关系

```
┌─────────────────────────────────────────────────────────────┐
│                    启动顺序                                   │
└─────────────────────────────────────────────────────────────┘

第 1 步: 启动基础服务
  ├─ PostgreSQL (5432)
  ├─ ETCD (2379)
  └─ NATS (4222)

第 2 步: 启动中心服务
  └─ Center 节点 (3010)
     ├─ 依赖: PostgreSQL, ETCD, NATS
     └─ 功能: 中心服务

第 3 步: 启动网关和游戏节点
  ├─ Gate 节点 (3011)
  │  ├─ 依赖: ETCD, NATS
  │  └─ 功能: 客户端连接管理
  │
  ├─ Game 节点 (3012)
  │  ├─ 依赖: PostgreSQL, ETCD, NATS
  │  └─ 功能: 游戏逻辑处理
  │
  └─ Web 节点 (3013)
     ├─ 依赖: ETCD, NATS
     └─ 功能: HTTP API

第 4 步: 验证部署
  └─ 所有节点就绪
```

## 资源分配

```
┌─────────────────────────────────────────────────────────────┐
│                    资源分配建议                               │
└─────────────────────────────────────────────────────────────┘

PostgreSQL:
  ├─ CPU: 2 核
  ├─ 内存: 2 GB
  └─ 存储: 10 GB+

ETCD:
  ├─ CPU: 1 核
  ├─ 内存: 1 GB
  └─ 存储: 5 GB

NATS:
  ├─ CPU: 1 核
  ├─ 内存: 1 GB
  └─ 存储: 5 GB

Center 节点:
  ├─ CPU: 1 核
  ├─ 内存: 512 MB
  └─ 存储: 1 GB

Gate 节点:
  ├─ CPU: 2 核
  ├─ 内存: 1 GB
  └─ 存储: 1 GB

Game 节点 (每个):
  ├─ CPU: 2 核
  ├─ 内存: 1 GB
  └─ 存储: 1 GB

Web 节点:
  ├─ CPU: 1 核
  ├─ 内存: 512 MB
  └─ 存储: 1 GB

总计 (单机):
  ├─ CPU: 8+ 核
  ├─ 内存: 8+ GB
  └─ 存储: 30+ GB
```

## 存储架构

```
┌─────────────────────────────────────────────────────────────┐
│                    存储架构                                   │
└─────────────────────────────────────────────────────────────┘

Docker Host 文件系统
  │
  ├─ /data/postgres/
  │  └─ PostgreSQL 数据文件
  │     ├─ base/
  │     ├─ global/
  │     ├─ pg_wal/
  │     └─ ...
  │
  ├─ /data/etcd/
  │  └─ ETCD 数据文件
  │     ├─ member/
  │     └─ ...
  │
  └─ Docker volumes
     ├─ postgres_data
     └─ etcd_data

容器内挂载点
  │
  ├─ PostgreSQL 容器
  │  └─ /var/lib/postgresql/data → /data/postgres
  │
  └─ ETCD 容器
     └─ /etcd-data → /data/etcd
```
